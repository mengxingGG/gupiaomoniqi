# AI 助手：记忆、上下文与对话交互

更新：2026-10-16；对应 1.1.1 当前实现。

## 入口与配置

仅 Android 提供助手。40 dp 白球配黑色三点表情，48 dp 点击区域，支持拖动、吸边与位置恢复；半屏以上面板只负责会话和对话。模型与记忆管理统一位于主 App 设置，不在球体里重复放管理页面。

设置包含 OpenAI Chat Completions、OpenAI Responses、DeepSeek 专项和 Claude Messages 四种接口，支持地址、密钥、模型列表/手填 ID、流式与工具续接测试、上下文和对应接口的思考设置。切换接口自动更新思考选项，默认自动，不发送非标准的 auto 参数。Claude 可选新模型自适应或旧模型预算。详细参数与验证范围见 [1.1.1 接口与搜索](1.1.1-接口与搜索.md)。

对话面板采用内存中的本应用背景快照做降采样模糊，叠加白色半透明面板；正文不参与模糊，兼容 Android 8+。打开/收起、窗口高度和会话侧栏都有过渡；主页面切换保留离场数据与列表位置。模拟用途提示集中在对话顶部。

## 固定规则与 3000 字符记忆

- 固定规则位于 `server/assistant/AGENT.md`，由项目维护者管理。模型没有修改此文件的工具。
- 每个账户一个 `memory.md`，以 Unicode 码点计数，最多 3000 字符，换行也计数。
- AI 通过 `update_memory` 自主提出完整替换内容；超限拒绝，不截断后半段。只记稳定偏好，不应保存临时行情和密钥。
- 记忆作为低信任资料注入，不提升到系统指令层；工具权限仍由服务器验证。
- 用户可以查看、手动修改、暂停、撤销已有非空版本、彻底清空。清空同时清除撤销副本。
- 使用修订号与写入代数做并发校验：运行中的旧请求不能覆盖用户刚改过或已清空的内容；冲突需要刷新后重试。
- 固定规则、记忆、会话历史是三种独立对象。关闭记忆后不注入或自动写入，但保留原文件便于恢复。

## 上下文预算

用户可选 32K、64K、128K、256K、512K、1M，默认 256K，选择值就是会话窗口。取消“模型实际容量”填写项，旧配置的 modelContextTokens 被忽略。提供方拒绝过大的请求时明确提示调整，不暗中降为 32K。

当前采用 UTF-8 字节上界估计，并计入工具描述、框架及输出预留；这不是提供方 tokenizer 的精确计费量。输出及思考合计通常预留 4096 token，高/超高 8192，最高强度 16384。

每次模型调用前检查估算用量，达到窗口的 80% 时自动压缩较早轮次，目标约 60%，同一会话继续。摘要保留目标、约束、事实、来源/时间和待办，当前问题保留；完整原文仍可在历史查看。长历史分片归纳，工具只在完成完整调用/结果轮次后压缩，不切断协议配对。摘要使用当前接口、自动思考、禁用工具，产生正常的模型调用费用。

摘要检查点加密持久化，重启后复用，删除会话一起清理；摘要失败、取消或截断时不推进检查点、不删除原记录。摘要作为低信任资料，不替代固定规则或 3000 字符长期记忆。只有当前问题且无法进一步压缩时不凭空缩短问题，超过窗口会提示缩短或调大。当前不提供完整历史的语义检索。

OpenAI 参数语义参考：[Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)。提供方的上下文、reasoning_effort 和工具支持仍应通过所选模型实测确认。

## 对话生命周期

- 服务端保存会话；客户端采用短间隔轮询读取流式正文和进度。面板收起不取消任务。
- 每账户同时一个任务，全局最多 20 个任务；最长 5 分钟，每次最多 6 轮模型调用、每轮最多 12 个工具请求。
- 每账户最多 100 个会话，每会话最多 500 条消息。请求 ID 去重，避免相同发送被重复执行。
- 主动停止、退出账户、删除运行中会话与服务关闭会取消任务。重启残留任务显示中断，不自动重试。
- 输入、停止、错误提示、来源和复制操作直接出现在聊天流程中。会话侧栏提供新建、搜索、置顶、重命名、删除。

## 数据权限

每个会话固定真实/虚拟模式与可选标的，新会话资金持仓、成交、自选和联网默认全部开启，用户可取消勾选；旧会话已保存的关闭状态不被覆盖。服务端再次验证工具与账户归属，不能仅靠模型提示词。

可用只读工具：报价、已有历史、全市场7天快照、个股详情、条件筛选、授权资金持仓、近期成交、自选、公开网页搜索和已检索页面的正文节选。写工具包含长期记忆与模拟交易提案；提案只生成授权卡，用户逐笔确认后才执行正常订单流程。联网开放给两种模拟盘，但真实世界新闻/报价不能替代虚拟股行情。财报数据通过公开披露检索，不冒充结构化全市场财务筛选。

全市场行情权限默认开启，旧会话未设置该字段时延续原有报价读取权限。两到三步查询：自选及报价速查 → 全部已收录股票近7个自然日日快照检索 → 候选个股详情/K线/按需盘口。各工具限定本会话市场模式，覆盖所有已收录标的，不局限于当前页面或自选；快照缺失日期不补造。输入栏可快捷调整上下文和本接口思考强度，账户级配置从下一条消息起生效。

Android 前台无交互15秒且无普通API请求时，每2秒最多同步50只当前市场股票；收起到后台或打开AI面板时停止启动新批次。SQLite按服务器地址、模式保存公开行情及断点，完成一轮后每15分钟继续滚动更新，成功整轮后移除下架股票，失败退避1分钟。服务器只读取本地已记录日数据、复用5分钟历史缓存、最多4个历史读取并发，不因快查触发全市场外部补拉。App将提问匹配到的最多20个缓存候选ID作为低信任检索线索发送；价格由服务器工具重新核对，不把缓存当作下单行情。

授权卡固定市场、股票、方向、数量、价格方式、理由与15分钟有效期。确认只传卡片ID，不接受改量改价；复用普通订单校验、冻结、撮合、T+1、费用和幂等键。结果区分挂单与成交，执行中禁删会话。中断后不自动重发，待核对卡须由用户明确点击恢复，并使用同一幂等键，防止重复成交。卡片只显示提交时结果，后续限价成交与撤销在正常订单页查看。

研究规则要求按问题深度检索财报/公告、近一年到半年/几个月新闻、公开社交平台讨论，核实主体、时间、原始来源及反对证据；爆料单独标记未证实。Exa 免费与 API 均支持日期、域名、财报/新闻分类，正文每页最多 6000 字符。登录或付费内容、未覆盖平台及不完整文档明确说明，不能声称读过全文。

固定 AGENT.md 明确本产品是练习与娱乐的模拟交易平台，真实行情模式也不连接券商。给出有依据的模拟练习方案和复盘思路，正文避免重复免责声明；具体数据缺口、规则约束与情景失效条件仍应解释。

## 存储与运维

助手数据目录优先使用 `ASSISTANT_DATA_DIR`，其次为 `DATABASE_DIR` 同级的 `assistant`，均未配置时使用已被 Git 忽略的 `server/data/assistant`。Linux 服务和 Windows 发布启动器均指定持久目录，独立于版本源码目录。按账户哈希隔离目录，API Key 使用 AES-256-GCM 加密，随机 `master.key` 与数据一起受服务账号权限保护。迁移必须一起保留密钥文件；不要把密钥、账户文件和测试配置推到 GitHub。发布包必须包含固定的 `server/assistant/AGENT.md`。

目前存储事务假设单个 Node 进程；多实例部署需要统一存储与跨进程锁，不能让多个进程直接写同一目录。网络传输限制重定向、私网目标和响应大小；内网模型仅由部署方显式配置 `ASSISTANT_ALLOWED_HOSTS` 后可用。

本轮验证覆盖四种协议的流式与工具续接、加密持久化、权限、80% 自动压缩、删除与搜索。Exa 免费搜索、日期/财报筛选和正文读取已请求官方公共服务；本机 Fake-IP 仅在隔离验收进程按官方域名放行。未使用真实付费模型或 Exa API 密钥验证服务商配额及最终回答质量。
