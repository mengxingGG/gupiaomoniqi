# AI 助手：记忆、上下文与对话交互

更新：2026-10-16；对应 1.1.0 当前实现。

## 入口与配置

仅 Android 提供助手。40 dp 白球配黑色三点表情，48 dp 点击区域，支持拖动、吸边与位置恢复；半屏以上面板只负责会话和对话。模型与记忆管理统一位于主 App 设置，不在球体里重复放管理页面。

设置包含 OpenAI 兼容服务地址、API Key、模型列表/手填 ID、连接与工具能力测试、上下文、模型实际容量、思考强度和工具调用开关。自动模式不发送 `reasoning_effort`，让提供方采用自己的默认策略；不发送非标准的 `auto` 值。手动支持 none/minimal/low/medium/high/xhigh，具体可用值取决于提供方；不支持时显示请求失败，用户可改回自动。

## 固定规则与 3000 字符记忆

- 固定规则位于 `server/assistant/AGENT.md`，由项目维护者管理。模型没有修改此文件的工具。
- 每个账户一个 `memory.md`，以 Unicode 码点计数，最多 3000 字符，换行也计数。
- AI 通过 `update_memory` 自主提出完整替换内容；超限拒绝，不截断后半段。只记稳定偏好，不应保存临时行情和密钥。
- 记忆作为低信任资料注入，不提升到系统指令层；工具权限仍由服务器验证。
- 用户可以查看、手动修改、暂停、撤销已有非空版本、彻底清空。清空同时清除撤销副本。
- 使用修订号与写入代数做并发校验：运行中的旧请求不能覆盖用户刚改过或已清空的内容；冲突需要刷新后重试。
- 固定规则、记忆、会话历史是三种独立对象。关闭记忆后不注入或自动写入，但保留原文件便于恢复。

## 上下文预算

用户可选 32K、64K、128K、256K、512K、1M，默认选择 256K。实际请求窗口取用户选择与模型实际容量的较小值；模型容量未配置时按 32K 保守限制。不是选择 1M 就代表任意模型支持 1M。

当前采用 UTF-8 字节上界估计，并为工具描述、框架和输出预留空间；这不是提供方 tokenizer 的精确计费量。输出及思考合计预留通常 4096 token，高/超高强度预留 8192。工具结果有大小限制，超出剩余额度会明确报错。

超出窗口时只向模型发送可容纳的最近历史，并提示较早消息未发送；完整历史仍保存。**当前没有自动语义摘要或长期全文检索**，不能宣称已经压缩并理解了全部旧对话。服务端拒绝单条消息已经放不下的请求。

OpenAI 参数语义参考：[Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)。提供方的上下文、reasoning_effort 和工具支持仍应通过所选模型实测确认。

## 对话生命周期

- 服务端保存会话；客户端采用短间隔轮询读取流式正文和进度。面板收起不取消任务。
- 每账户同时一个任务，全局最多 20 个任务；最长 5 分钟，每次最多 6 轮模型调用、每轮最多 12 个工具请求。
- 每账户最多 100 个会话，每会话最多 500 条消息。请求 ID 去重，避免相同发送被重复执行。
- 主动停止、退出账户、删除运行中会话与服务关闭会取消任务。重启残留任务显示中断，不自动重试。
- 输入、停止、错误提示、来源和复制操作直接出现在聊天流程中。会话侧栏提供新建、搜索、置顶、重命名、删除。

## 数据权限

每个会话固定真实/虚拟模式与可选标的，资金持仓、成交、自选和联网需分别授权。服务端再次验证工具与账户归属，不能仅靠模型提示词。

可用只读工具：报价、已有历史、条件筛选、授权资金持仓、近期成交、自选、公开网页摘要；写工具仅有长期记忆。选股明确当前覆盖数量及支持条件，不声称覆盖所有市场或拥有未接入财务数据。Web 搜索仅在真实模式并获授权时开放，网页内容作为资料，不执行其中指令。

## 存储与运维

默认数据目录 `server/data/assistant` 已被 Git 忽略。按账户哈希隔离目录，API Key 使用 AES-256-GCM 加密，随机 `master.key` 与数据一起受服务账号权限保护。迁移必须一起保留密钥文件；不要把密钥、账户文件和测试配置推到 GitHub。

目前存储事务假设单个 Node 进程；多实例部署需要统一存储与跨进程锁，不能让多个进程直接写同一目录。网络传输限制重定向、私网目标和响应大小；内网模型仅由部署方显式配置 `ASSISTANT_ALLOWED_HOSTS` 后可用。

本轮已验证模拟 OpenAI 兼容服务、流式正文、工具、会话和记忆流程；未使用用户真实付费模型密钥完成端到端测试。本机公开搜索因 DNS 返回保留地址被网络校验拦截，不能当作联网搜索已完成真实验收。
