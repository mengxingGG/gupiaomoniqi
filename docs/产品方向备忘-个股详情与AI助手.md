# 产品方向备忘：个股详情与 AI 助手

更新：2026-10-16。本文记录本轮已经确定并实现的范围，替代此前讨论稿。原始备忘仍保留在用户 Downloads 目录；后续聊天中的明确要求优先。

## 产品边界

- Android 提供行情、模拟交易和用户 AI 助手；Web 提供行情、模拟交易、App 下载，**不提供 AI 助手**。
- 真实行情和虚拟市场的账户资金、持仓、成交、走势以及 AI 查询范围相互隔离。
- 助手只读分析与选股，不代用户下单。模拟市场的规则 AI 交易者是另一套服务，不等同于用户助手。

## 个股详情与 K 线

参考东方财富截图的信息层级、白底、细网格和细线图标，不复制其品牌、交易入口或没有来源的数据。

1. 股票名、市场、代码、自选入口在顶部；报价、涨跌、开高低昨收、成交量与每手数量紧凑排列。
2. 明确行情模式、显示币种、交易结算规则、最近更新时间；大字体或窄屏改为上下排列，避免强行塞入一行。
3. K 线使用红色空心上涨柱、绿色实心下跌柱、细影线、MA5/10/20、可见区间高低点与实际日期轴。
4. Android 支持十字光标、历史翻页、可见根数缩放、全屏、成交量/MACD 副图。Web 提供 K 线、均线、OHLC 读数、指针/键盘选择和 MACD 开关。
5. 盘口与持仓分区；图标采用统一线宽，触摸热区大于图案本身。

当前仍沿用已有分时、日 K、月 K、年 K 数据范围；五日、周 K、复权切换、十档盘口及券商队列尚未接入。市盈率、市净率、市值、真实成交量单位等未完成字段核验时不补造显示。

## Android AI 入口

- 小白球：40 dp 白色球面，48 dp 触摸区域，黑色两眼一嘴三个点，轻微呼吸/眨眼和任务状态提示。
- 可拖动、自动吸附左右边缘、保存位置，屏幕变化后限制在可见区域。
- 点击打开超过半屏的对话面板，可切全屏。球体面板只包含对话、会话管理和会话数据授权。
- **模型、密钥、上下文、思考与记忆管理统一放在 App 设置 → AI 助手管理。** 后续这一要求覆盖最初“输入框里放设置”的提议。

## 会话与分析

侧边栏提供新建、搜索、置顶、改名、删除；主窗口提供当前范围、消息、来源链接、复制、输入和发送/停止。任务在服务器运行，收起面板后继续；重新打开读取进度和已有回复。停止、登出、删除运行中的会话会取消对应任务。服务器重启后显示中断，不自动重发付费请求。

用户填写 OpenAI 兼容 URL/Key，读取模型列表或手填模型 ID，测试连接及工具调用能力。密钥由服务端加密保存，界面只显示“已保存”，变更服务地址清除旧密钥。真实股票查询可在用户授权后检索公开网页摘要，返回来源链接，不能伪称读过全文。

详见 [AI 助手实现与边界](AI助手-记忆上下文与对话交互.md)。

## Web 下载

页头提供 App 下载按钮，展示服务器更新接口返回的版本、大小、说明、SHA-256、APK 链接与移动访问二维码。无发布版本、请求失败提供明确状态与重试。二维码仅用于可公开访问的 HTTPS 地址。APK 需由原有发布脚本放入服务器更新目录后才对公网可下载。

## 备忘中的 Python 回退缺陷

原备忘指出生产构建在 Linux 调用了 `where.exe` 和不存在的 `python`。本地源码已具有平台分支，但检查发现股票列表和盘口请求未进入 Python 回退，仅历史行情接入。

本轮补全列表、盘口的回退路径；Linux 优先 `python3`，Windows 才运行 `where.exe`，支持 `PYTHON_EXECUTABLE`。只在解释器 ENOENT 时换命令，网络错误不遍历所有解释器；重试共享时间预算、支持取消，429 不绕过限流。Linux 分支和回退入口已通过自动测试。生产 Linux 的实际运行文件和网络恢复需要部署后另行验证。

## 模拟股长期静止问题

已修复低价股每轮取整丢掉微小变化、行业因子按股票重复抽样、过强昨收锚定，以及规则 AI 累计成交量偏置和仓位到顶后的停滞。价格引擎内部保留小数累积，交易者使用趋势、回调、量速、分批止盈与现金保留。具体测试与真实参考见 [交付与验收](1.1.0-交付与验收.md)。

已接入按股票智能补缺：东财成功的股票保留，仅对缺失股票和所需数据类型请求备用源；报价使用单一来源完整快照，不拼接不同来源字段。实际支持市场、周期及限制见 [行情数据多路线评估](行情数据多路线评估.md)。
