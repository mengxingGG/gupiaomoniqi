# 股票模拟器（gupiaomoniqi）项目文档

> 本文档基于重构前（v2.0 阶段）代码梳理而成，用于记录旧版架构、核心算法与 UI 设计，作为后续重新开发的参考基线。
> 2026-07-27 已进一步核对 Git 的 `origin/master` 与 `a725f4a` 两条历史线。详细的继承项、缺陷和新版落法见 [旧版算法审计与继承清单.md](./旧版算法审计与继承清单.md)。

## 1. 整体架构

| 模块 | 技术栈 | 说明 |
|---|---|---|
| `client`（PC 端） | React 18 + TypeScript + Vite + Zustand + TailwindCSS + Headless UI + ECharts/lightweight-charts + Axios | 按业务分组件：`market/trade/portfolio/ranking/loan/achievement/settings/history/layout/common` |
| `server`（后端） | Node.js + TypeScript + Fastify + Drizzle ORM + better-sqlite3 + bcrypt + zod | `routes`（REST）、`services`（业务逻辑）、`market`（行情/AI 引擎）、`db`（schema + 工具） |
| `shared` | `shared/types/api.ts` | 前后端共享的 API 类型定义 |
| `mobile-app` | Vue 3 + TypeScript + Vite + Pinia + Vue Router + Vant + Capacitor | 功能较精简：登录/注册/持仓/个人中心/股票详情 |

架构模式：**服务端权威**。`server` 是唯一数据源和行情/撮合逻辑执行者，`client` 通过 REST + WebSocket（`/ws/market`）消费数据；`mobile-app` 是独立的 Vue/Vant 客户端。

> 注：`client/src/core/{models,constants,utils}` 中存在一套旧的“客户端本地模拟”逻辑（含手续费买0.5%/卖0.3%、借款上限3倍本金、1000个AI交易者等参数），与当前 server 端实际参数（手续费万三、借款上限为总资产50%、AI 每轮仅激活5-10个）明显不一致，判断为遗留代码，重新开发时不必参照。

## 2. 核心业务算法

| 算法 | 原实现位置 | 思路 |
|---|---|---|
| 股价随机游走 | `server/src/market/MarketEngine.ts` → `updateStockPriceInTransaction()` | 每 5 秒对每只股票：`newPrice = price * (1 + (Math.random()-0.5)*0.04)`，单次最大波动 ±2% |
| AI 压力叠加 | 同上 → `addAIPressure()`/`getAIPressure()` | AI 买卖后累积净买卖量，行情 tick 时按 `pressure/10000*0.01` 叠加到价格，每轮清零 |
| 涨跌停限制 | 同上 | `limitUp = previousClose*1.10`，`limitDown = previousClose*0.90`，夹紧价格 |
| 价格历史存储 | `recordPriceHistory()` | 每 30 秒记一次 K 线点，JSON 累计超 3GB 时 FIFO 移除最旧记录 |
| AI 交易决策（普通） | `server/src/market/AIEngine.ts` → `simulateDecision()`/`selectStockForBuy()`/`selectPositionForSell()` | 7 种策略（保守/激进/价值/技术/随机/动量/逆向），结合现金占比、闲置轮数动态调整权重 |
| AI 交易决策（智能） | `AIEngine.ts` → `smartDecision()` + `server/src/services/OllamaService.ts` | 调用本地 Ollama LLM，传入市场快照+持仓构造 prompt，解析 buy/sell/hold 决策，含兜底校验 |
| AI 交易执行 | `AIEngine.ts` → `executeDecision()`/`runAITradingRound()` | 每轮随机挑 5-10 个交易者（优先智能 AI）异步执行，3 秒后重算总资产 |
| 用户买卖撮合 | `server/src/services/TradeService.ts` → `buy()`/`sell()` | 市价单立即成交；限价单未达触发条件置为 `PENDING` 并冻结资金/持仓；成交时更新持仓均价，扣手续费万三（买卖统一） |
| 限价单后续撮合 | `server/src/services/OrderExecutor.ts` → `checkAndExecutePendingOrders()`，每 5 秒轮询 | 买单 `currentPrice <= limitPrice` 或卖单 `currentPrice >= limitPrice` 时成交 |
| T+1/T+0 规则 | `TradeService.isT0Market()` | 市场代码以 `_T0` 结尾为 T+0（港股/美股/期货），否则 T+1；每日 0 点重置可卖数量 |
| 借贷利息/额度 | `server/src/services/LoanService.ts` → `borrow()`/`repay()` | 借款上限=总资产 50%，年利率 17%，支持部分还款 |
| 排行榜 | `server/src/services/RankingService.ts` → `computeRanking()`/`computeAIRanking()` | 合并真实玩家与 AI 交易者，按 `total_assets` 降序排名，结果缓存 10 分钟 |
| 成就系统 | `server/src/services/AchievementService.ts` | 12 项成就，基于 SQL 条件判断，交易后触发检查 |
| 定时任务 | `server/src/app.ts` | 5 秒行情引擎、5 秒限价单撮合、5 分钟 AI 交易轮、每日 0 点 T+1 重置；行情通过 WebSocket 广播 `price_update` |

## 3. UI 设计

### client（PC 端，React + Tailwind + Headless UI）

主要页面（`src/pages`）：
- `LoginPage` — 登录/注册
- `TradingPage` — 核心交易页：左侧市场/股票列表，中间 K 线图，右侧买卖面板 + 委托簿
- `PortfolioPage` — 持仓（资产总览 + 持仓列表）
- `OrdersPage` — 委托单列表
- `HistoryPage` — 成交历史/资金流水
- `LoanPage` — 借贷面板
- `RankingPage` — 排行榜
- `AchievementPage` — 成就墙
- 全局布局：`MainLayout` + `Header` + `Sidebar`；`SettingsModal`（主题切换、礼包码、帮助）

风格：涨跌配色符合 A 股习惯（涨红 `#ff4d4f` / 跌绿 `#52c41a`），主色近 Ant Design 蓝 `#1890ff`，支持明暗主题切换，字体 Inter + Fira Code（等宽数字）。整体是类同花顺/东方财富的密集信息交易软件风格，左右分栏布局。

### mobile-app（Vue 3 + Vant）

主要页面（`src/views`）：`Home`（行情首页）、`Login`/`Register`、`Portfolio`（持仓）、`Profile`（个人中心）、`StockDetail`（股票详情）。Vant 组件库，风格轻量、卡片式。功能范围明显小于 PC 端（无独立交易面板/排行榜/借贷/成就页面）。

## 4. 数据库/数据模型（Drizzle + SQLite）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `accounts` | id, username, passwordHash, displayName, createdAt, lastLoginAt | 登录凭据 |
| `players` | id, cash, initialCash, totalAssets, tradingDay, isPaused | 玩家资产档案 |
| `positions` | id, playerId, stockCode, quantity, availableQuantity, averageCost, totalCost, buyDate | 持仓 |
| `orders` | id, playerId, stockCode, type, orderMode, quantity, price, executedPrice, status, fee | 委托单 |
| `transactions` | id, playerId, stockCode, type, quantity, price, total, fee, createdAt | 成交流水 |
| `loans` | id, playerId, principal, interest, annualRate, status, borrowDate, lastInterestAt | 借贷记录 |
| `achievements` | playerId, achievementId, unlockedAt | 已解锁成就 |
| `giftCodeUsage` | playerId, code, usedAt | 礼包码使用记录 |
| `stocks` | code(PK), name, market, industry, currentPrice, previousClose, openPrice, high/lowPrice, volume, turnover, changePercent/Amount, priceHistory(JSON), updatedAt | 股票行情表 |
| `aiTraders` | id, name, cash, totalAssets, strategyType, psychologyType, isSmart, lastDecisionAt | AI 交易者档案 |
| `aiPositions` | id, traderId, stockCode, quantity, averageCost | AI 持仓 |

礼包码配置、种子股票、LLM 配置存于 `server/data/{gift-codes.json, initial-stocks.json, llm-config.json}`（JSON 文件，非表）。

## 6. 重新开发说明

本文档记录的是**重构前**的实现。旧版在业务覆盖面上已经相对完整，尤其是多策略 AI、订单生命周期、T+0/T+1、图表、排行榜和账户体系，因此新版应把它当作业务规则参考库，而不是全部推倒后重新猜规则。

但“概念完整”不等于“实现可以照搬”。历史代码中已经确认有限价单双扣资金/双冻结持仓、撤单退款不完整、AI 调度量远小于种子规模、排行榜初始资产常量错误、客户端与服务端手续费冲突、历史行情 JSON 膨胀等问题。新版按审计清单逐条继承与修正。
