# 1.1.1：助手接口、检索与交互

日期：2026-10-16。Android versionName 1.1.1，versionCode 9。

## 接口与思考设置

| 接口 | 请求 | 手动思考参数 | 续接处理 |
| --- | --- | --- | --- |
| OpenAI Chat Completions | `/chat/completions` | `reasoning_effort` | tool_calls / tool_call_id |
| OpenAI Responses | `/responses` | `reasoning.effort` | function_call_output、加密 reasoning item |
| DeepSeek 专项 | `/chat/completions` | thinking.enabled/disabled + low/high/max | 保留 reasoning_content 与工具结果 |
| Claude Messages | `/messages` | adaptive + output_config.effort，或旧模型 budget_tokens | 签名 thinking、tool_use/tool_result |

默认自动省略思考参数，采用模型服务默认策略。切换接口更新可选强度并恢复自动。Claude 旧模型预算分为 1024/2048/4096；新模型手动强度提供 low/medium/high/xhigh/max，但具体模型可能只接受其中部分，接口报错会展示调整提示。

模型地址可填官方或兼容网关，模型 ID 支持读取列表/手填。Claude 使用 x-api-key、anthropic-version，不混发 Bearer。两轮连接测试验证工具调用后的正文续接。协议私有信息加密保存，不通过公开会话接口返回；更换接口、地址、模型或密钥后不会复用旧协议签名。

## 上下文与权限

上下文选择 32K、64K、128K、256K、512K、1M，默认 256K，选择即为有效预算。移除模型容量配置及旧 32K 二次限制。估算用量达到 80% 自动生成语义摘要，保留近期内容与当前问题，同一会话继续，完整历史保留。摘要检查点持久化；失败不推进，删除会话一起清理。详情见 [上下文设计](AI助手-记忆上下文与对话交互.md)。

新会话全部股票行情、持仓、成交、自选、联网权限全开，工具和记忆默认开启；用户主动关闭或旧会话既有关闭状态仍有效。输入栏可快捷设置上下文与对应接口的思考强度。

## 授权交易与行情快查

AI可以生成模拟买卖授权卡，显示固定市场、股票、方向、数量、市价/限价、参考价与时间、预计金额、理由和15分钟有效期。创建卡片不产生订单；用户逐笔确认后才执行，拒绝或过期不执行。服务端校验账户归属，不接受确认请求改写交易参数，复用正常订单服务检查资金、可卖持仓、T+1与整手规则，扣费、冻结、撮合与普通手动交易相同。重复点击或服务中断恢复始终沿用同一卡片幂等键，结果待核对时不自动重发。AI没有确认、撤单、改余额工具。两种市场均为模拟交易。

新增 `market_scan` / `market_detail`：先速查自选报价，再检索当前模式全部股票近7个自然日已有日快照，最后按需读取候选详情、历史与盘口。支持名称、代码、ID、市场筛选与分页，缺数据不插值。App空闲15秒后每2秒最多同步50只，SQLite按服务器/模式保存断点；完整同步后按15分钟周期刷新，后台/AI面板停止新批次，异常退避。提问中的股票名称/代码匹配本地缓存后回传候选ID，AI再核对服务器数据。具体边界见 [助手设计](AI助手-记忆上下文与对话交互.md)。

## 搜索和研究

- Exa 免费：免密钥的官方 MCP 搜索。简单查询使用 web_search_exa；日期、域名及财报/新闻分类使用 web_search_advanced_exa。不会因免费限流偷偷切换付费接口。
- Exa API：独立密钥，使用 `/search` 和 `/contents`；与模型密钥分开加密保存。保留 Bing RSS 作为可选搜索方式。
- 每次搜索默认 5 条，可选 1–8 条；每条保留最多 2000 字符与发布日期。正文读取最多 3 个已搜索链接，每页 6000 字符。支持继续分批检索，不能据节选宣称读完完整财报。
- 固定规则要求按研究需要覆盖财报公告、近一年/半年/数月新闻、公开社交讨论与爆料；区分事实、观点、未证实信息，查原始来源和相反证据。搜索未覆盖、登录/付费墙及来源冲突如实说明。
- 虚拟股使用平台行情，不能把真实同名公司新闻作为虚拟股驱动事实。真实行情盘也仅是模拟交易。建议围绕练习条件、模拟仓位、失效情景与复盘，不反复输出套话免责声明。

## 交互与删除修复

Android 主页面使用短距离位移和淡入淡出，离场保留最后数据帧，列表位置按页保存。AI 对话使用本应用视图的降采样模糊背景、白色半透明面板及清晰正文；背景只在内存处理，无截图权限、无文件落盘。展开约 300ms，收起约 220ms，窗口高度与侧栏均有过渡，尊重系统动画时长设置。

会话删除在模拟器复现 HTTP 415 `Unsupported Media Type`：Android 给无请求体 DELETE 添加 `application/x-www-form-urlencoded` 和 Content-Length 0。客户端改为显式 JSON `{}`，同时修复共用该请求路径的空 DELETE 撤单。回归覆盖请求方法、身份、JSON 内容类型、删除后列表与服务重启持久化。
