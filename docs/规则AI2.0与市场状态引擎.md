# 规则 AI 2.0 与市场状态引擎

本轮只实现后端服务，不修改 Web 或 Android。现有虚拟股票、真实行情模拟盘和不连接券商的产品边界保持不变。

## 目标

旧行情主要由零均值随机波动、前收盘均值回归和快速衰减的订单流构成；旧规则 AI 主要依赖随机买入概率、日内评分和固定止盈止损。因此成交很活跃，但缺少持续数日或数周的公司趋势。

新引擎把价格拆成多个时间尺度：

```text
长期价格锚 = 公司基本价值 × exp(所有权溢价 + 事件情绪)

价格变化 =
  向长期价格锚收敛
  + 市场/行业阶段漂移
  + 即时订单流冲击
  + 按时间尺度缩放的微观噪声
```

## 持久状态

迁移版本 15 新增：

- `virtual_instrument_states`：公司价值、质量、成长、杠杆风险、周期敏感度、模拟流通股和所有权状态；
- `virtual_market_regimes`：市场或行业的牛市、中性、熊市阶段、日漂移和波动率倍数；
- `virtual_market_events`：事件范围、基本价值冲击、情绪冲击、波动率、起止时间、半衰期和已应用进度；
- `positions.opened_at`：连续持仓开始时间；
- `ai_traders` 投资逻辑字段：周期、信心、核心标的、逻辑分数、开始时间、最短持有期和信号版本。

服务重启会恢复这些状态，不会重新随机生成公司质量、事件进度或市场阶段。

## 公司基本价值

每只股票拥有确定性生成的质量、成长、杠杆风险和周期敏感度。相同股票在重启后不会变成另一家公司。基本价值按日级速度缓慢变化，并受到已经确认的事件逐步修正。

基本价值不会被玩家或 AI 直接修改。资金行为改变的是成交价格、流动性和估值/所有权溢价；经营类事件才改变公司的长期价值。

## 长期资金与所有权溢价

持仓信号以持股数量占模拟流通盘的比例为基础，不使用上涨后的持仓市值，避免“价格上涨 → 信号放大 → 再上涨”的自反馈漏洞。

```text
加权所有权 =
  持股占流通盘比例
  × 持有时间权重
  × 参与者稳定度
  × 历史可信度
```

- 玩家长期资金权重最高；
- LLM 持仓使用相同经济规则；
- 规则 AI 按短线、波段、长期周期给予不同稳定度；
- 新买入先获得有限的即时长期信号，持有数日后逐步增强；
- 溢价使用平方根和上限约束，不能无限复利；
- 极端集中持仓会产生折价与更高退出风险；
- 减仓会降低所有权信号，并同时产生卖出订单流冲击。

## 事件生命周期

事件可以作用于整个市场、行业或单只股票。每个事件独立声明：

- 总基本价值冲击；
- 短期情绪冲击；
- 波动率倍数；
- 开始、结束和衰减半衰期；
- 已经应用到基本价值的比例。

基本价值冲击在事件期间逐步落地并永久进入当时的价值基线；情绪与额外波动在事件结束后按半衰期衰减。自动模拟事件默认开启，可用 `VIRTUAL_MARKET_EVENTS_ENABLED=false` 关闭。

当前只开放只读接口：

- `GET /api/ai/market-state/status`
- `GET /api/ai/market-events?limit=20`

事件创建保留为后端内部能力，尚未在没有管理员鉴权的公网接口上开放写操作。

## 规则 AI 2.0

规则 AI 不再每轮重新随机选择是否交易。每名 AI 持久化投资逻辑，并按照策略分配投资周期：

| 策略 | 默认周期 | 主要依据 |
| --- | --- | --- |
| 价值、稳健 | 长期 | 价值偏离、质量、杠杆、所有权信号 |
| 动量、技术、逆向、均衡 | 波段 | 周期、趋势、价值偏离与事件 |
| 进取 | 短线 | 事件、波动、趋势和成交活跃度 |

AI 建仓后记录核心标的、逻辑分数、信心与最短持有期限。逻辑继续成立时不会因为统一止盈线反复卖出；严重负面事件、风险止损或逻辑失效仍可提前退出。

## CPU 设计

- 全市场因子在行情版本变化时统一计算一次；
- 每个策略和市场的候选排序按版本缓存；
- 5000 名 AI 读取共享排名，不再分别扫描 1200 只股票；
- 市场状态每 tick 做 O(股票数) 的轻量更新；
- 所有权聚合每分钟一次；
- 状态批量持久化默认每 5 分钟一次；
- 短线、波段、长期 AI 的复核间隔分别扩大，降低无效高频轮询。

## 验收

自动化测试覆盖：

- 20 日加速回放产生横截面趋势分化；
- 事件逐步修改价值，情绪按半衰期衰减；
- 巨量持仓产生即时冲击和随时间增强的所有权溢价；
- 数据库重建后恢复价值、阶段、事件进度和 AI 投资逻辑；
- 长期 AI 在逻辑有效时坚持持有，在严重恶化时退出；
- 原有日涨跌停、单 tick 冲击、T+0/T+1、限价单和账户隔离测试继续通过。

隔离内存数据库基准可通过以下命令复测，不会接触正式数据：

```powershell
npm run ai:v2:benchmark -- 320 5000
```

本次本机基准使用 1200 只股票、5000 名规则 AI、每轮 320 人：启动约 1.49 秒；首轮约 449 毫秒；复用同一市场因子版本的第二轮约 363 毫秒；第二轮后 V8 `heapUsed` 约 124 MB。该数据用于回归比较，不等同于四核生产机的承诺值。

后续应继续进行 30/90 日批量回放，按趋势持续天数、上涨/下跌股票比例、收益自相关、波动聚集、换手率、最大回撤和事件响应曲线校准参数。
