# v1.0.3

本版本修复生产配置路径与邮箱验证码闭环，并保持 Android 生产服务固定为 `https://gupiaomoniqi.org`。

## 修复

- 统一 `config.json` 路径解析：显式路径、`APP_CONFIG_PATH`、工作目录依次回落；Linux systemd 固定使用 `/var/lib/gupiaomoniqi/config.json`，配置缺失不会因监听 `ENOENT` 崩溃。
- SMTP 可直接写入持久 `config.json`，同时保留环境变量最高优先级；支持 QQ 邮箱 `smtp.qq.com:465` SSL 与授权码。
- 补齐未登录注册邮箱发码、验证码校验、短期一次性注册凭证和事务内消费；不再跳过邮箱真实性验证。
- 保留旧账户登录/自动登录后的强制补邮箱卡片、邮箱或用户名登录、六位码找回密码及服务器本机紧急改密。
- 根配置中的 LLM 与 SMTP 独立校验；其中一段错误不会连带停用另一段。

## 客户端

- Web 与 Android 注册页改为“发送注册验证码 → 输入六位码 → 验证并注册”。
- Android `versionName` 为 `1.0.3`，`versionCode` 为 `7`，生产域名固定为 `https://gupiaomoniqi.org`。

## 部署提醒

Release 发布源码与 APK，不代表线上服务器已自动部署。部署后应确认 `/api/health` 返回 `emailDelivery.configured: true`，并实际收取一次注册验证码。
